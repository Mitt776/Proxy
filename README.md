# MitM

Прокси-клиент на базе ядра [sing-box](https://github.com/SagerNet/sing-box) — для **Windows** и
**Android**. Перехватывает трафик и заворачивает его через прокси.

На Windows — портативное приложение **без установки**: GUI на [Wails](https://wails.io)
(Go + WebView2 + Svelte), ядро отдельным процессом, управляется через сгенерированный конфиг и
Clash API. На Android — APK для ручной установки: тот же интерфейс в WebView, ядро линкуется в
приложение библиотекой (иначе на телефоне никак — см. [«Android»](#android)).

> Версия **2.1.0**

## Возможности

- **Протоколы:** VLESS (Reality / XTLS-Vision / ws / grpc / http / httpupgrade), VMess, Trojan,
  Shadowsocks, Hysteria2, TUIC, AnyTLS. Плюс **XHTTP** — при использовании альтернативного ядра
  (см. [«Два ядра»](#два-ядра)).
- **Два режима перехвата:**
  - *системный прокси* — без прав администратора;
  - *TUN* — весь трафик системы (запрос UAC, `wintun.dll` в комплекте). QUIC режется и трафик
    идёт только по IPv4 — иначе на TCP-нодах ломаются Google/YouTube.
- **Профили и подписки:** ссылки `vless://…`, готовый JSON или подписки (sing-box JSON /
  Clash YAML / base64); имя профиля формируется автоматически. Импорт из **QR-картинки** и показ
  QR ноды для переноса на телефон. **Автообновление подписок** по расписанию.
- **Маршрутизация:** один упорядоченный список правил, выигрывает первое совпавшее. Ловим по
  домену (точно / суффикс / подстрока / регулярка), IP, порту, процессу, протоколу, сети или
  набору правил; шлём через прокси, напрямую или в блок. Поверх — режимы Clash API
  «Правила / Глобально / Напрямую», переключаются **без перезапуска ядра**.
  - **Группы нод** — свои selector/urltest, чтобы разные правила уходили через разные ноды.
  - **Наборы правил** — готовые `.srs` (РФ напрямую, блок рекламы), удалённые наборы по URL и
    **текстовые списки `.lst`**: приложение само скачивает список доменов и конвертирует его в
    набор, понятный ядру.
  - **Проверка домена** — показывает, куда уйдёт домен, ещё до подключения; матчинг считает само
    ядро (`sing-box rule-set match`), а не наша реализация.
  - **Резать TLS-приветствие** — фрагментация ClientHello для правил «Напрямую»: имя сайта
    попадает на границу двух пакетов и простой DPI его не собирает.
- **Наблюдаемость:** вкладка «Трафик» — живые соединения с доменом из sniff-а, цепочкой outbound-ов
  и **сработавшим правилом глазами ядра**; оттуда же соединение обрывается или превращается в
  правило. Вкладка «Журнал» — вывод ядра с фильтром по уровню и подстроке.
- **Экран подключения:** 3D-кнопка, таймер соединения, флаг и страна внешнего IP, спарклайны
  приёма/отдачи/задержки/соединений, пинг нод и авто-выбор лучшей (urltest).
- **Двуязычность:** русский и английский, переключаются **на лету** — вместе с меню трея.
  По умолчанию язык берётся из локали Windows.
- **Отделка:** безрамочное окно со своей шапкой, заставка при запуске, трей со сворачиванием и
  уведомлениями, скорость в подсказке трея, автозапуск с Windows, одна копия приложения
  (single instance), аккуратная очистка системы при выходе и падении ядра (job object убивает
  ядро вместе с GUI).

## Скачать и запустить

Готовое приложение — в разделе [**Releases**](../../releases): распакуй
`MitM-portable-<версия>-win64.zip` в любую папку (или на флэшку) и запусти `MitM.exe`.
Установка не требуется, данные (профили/настройки/правила) хранятся рядом в `data\`.

## Android

`MitM-<версия>.apk` из того же раздела [Releases](../../releases), только `arm64-v8a`
(64-битные телефоны, Android 7.0 и новее). Магазина нет — ставится вручную, поэтому система
спросит разрешение на установку из этого источника. APK подписан своим ключом; отпечаток
сертификата и SHA-256 файла публикуются в заметках релиза — **обновления обязаны приходить с
тем же отпечатком**, иначе это чужая сборка, а не новая версия.

Разделы те же, кроме «Трафика»: подключение, профили, маршрутизация, журнал, настройки. Отличия
от Windows — по существу платформы, а не по недоделанности:

- **Ядро внутри приложения.** `/dev/net/tun` без рута недоступен, туннель выдаёт `VpnService`
  файловым дескриптором в процесс — отдельного процесса с ядром на Android не существует в
  принципе. Отсюда GPLv3 на Android-часть (см. [«Лицензии»](#лицензии)).
- **Разделение по приложениям — системное.** Список «мимо VPN» уходит в
  `VpnService.Builder.addDisallowedApplication`; правил по процессу внутри ядра нет.
  Список задаётся в момент подключения, к живому туннелю не применяется.
- **Импорт профиля** — из буфера, QR с камеры или QR из галереи.
- **Нет** проверки домена, автозапуска, трея и выбора файла ядра — вместо последнего форк с
  XHTTP вкомпилирован сразу.
- Соединение живёт в foreground-сервисе с уведомлением; автозапуска после перезагрузки и
  режима always-on нет.

## Два ядра

В архиве два ядра в `assets\`:

| Файл | Ядро | Назначение |
|------|------|-----------|
| `sing-box.exe` | официальное (стабильное) | по умолчанию |
| `sing-box-xhttp.exe` | форк [sing-box-lx](https://github.com/Leadaxe/sing-box-lx) (`with_xhttp`) | для нод `type=xhttp` |

Переключение — в приложении: **«Настройки» → «Ядро» → «Выбрать ядро…»**. Выбор запоминается и
переносится вместе с папкой (портативно, с любой буквы диска).

## Сборка из исходников

Нужны: [Go](https://go.dev) 1.23+, [Wails v2](https://wails.io/docs/gettingstarted/installation),
Node.js.

```sh
wails build          # соберёт build\bin\MitM.exe
```

> Бинарники ядра/`wintun.dll`/гео-базы (`assets\*.exe`, `*.dll`, `*.db`, `*.srs`) в git не хранятся
> — возьми их из архива в [Releases](../../releases) и положи в `assets\` перед сборкой.

Тесты: `go test ./...`; интеграционные (нужен реальный `sing-box.exe`) — под тегом `coretest`
с переменными `PROXY_ASSETS` и `PROXY_TEST_LINK`.

### Android

Нужны `ANDROID_HOME`, `ANDROID_NDK_HOME` и JDK 17+.

```powershell
.\scripts\android-deps.ps1        # разово: клон патченого wireguard-go + gomobile
.\scripts\android-build.ps1       # отладочный APK (arm64 + x86_64)
.\scripts\android-build.ps1 -Release
```

Скрипт делает `gomobile bind` (Go-модуль [mobile/](mobile/) → `android/app/libs/mitm.aar`),
собирает интерфейс и запускает Gradle. **AAR обязателен к пересборке после любой правки в
`mobile/`**: Gradle подхватывает готовый файл и об изменениях в Go не знает.

Релизная сборка подписывается ключом из `android/local.properties` (`mitm.storeFile`,
`mitm.storePassword`, `mitm.keyAlias`, `mitm.keyPassword`). Файла в репозитории нет, и без него
`assembleRelease` просто выдаёт неподписанный APK, а не падает.

## Технологии

Go · Wails v2 · Svelte + TypeScript · Kotlin + VpnService · sing-box · Clash API

## Лицензии

**Windows-часть.** GUI — авторский. Ядро sing-box и форк sing-box-lx распространяются под
**GPLv3** и подключаются **отдельными процессами**; их исходники — по ссылкам выше.

**Android-часть — [GPLv3](android/LICENSE)**, вместе с исходным кодом: там ядро линкуется в
приложение библиотекой, и иначе быть не может — туннель приходит от `VpnService` внутрь
процесса. Под лицензию попадают [android/](android/) и [mobile/](mobile/); полный текст едет
в самом APK и открывается в разделе «О программе». Общий с Windows код (`backend/`, `frontend/`)
собирается в APK на тех же условиях.

В комплект также входят базы geoip/geosite. Флаги стран — набор
[circle-flags](https://github.com/HatScripts/circle-flags) (MIT), шрифт
[Inter](https://github.com/rsms/inter) (SIL OFL 1.1).
