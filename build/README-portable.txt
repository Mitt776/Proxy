MitM — портативный прокси-клиент для Windows (на базе sing-box)
================================================================

КАК ЗАПУСТИТЬ
-------------
1. Распакуй всю папку в любое место (например, на флешку или в C:\MitM).
   Установка не требуется.
2. Запусти MitM.exe.
3. Добавь профиль на вкладке «Профили» -> «Добавить профиль»:
   - «URL подключения» — вставь ссылки vless:// / vmess:// / trojan:// / ss:// /
     hysteria2:// / tuic:// / anytls:// (по одной в строке) или готовый JSON;
   - «Подписка» — укажи URL подписки (sing-box JSON, Clash YAML или base64);
   - «Импорт из QR» — картинка с QR-кодом ноды.
4. Вернись на «Подключение» и нажми большую кнопку.

ЯЗЫК
----
Русский и английский, переключатель в правом верхнем углу окна. Меняется на
лету, вместе с меню в трее. По умолчанию берётся из языка Windows.

РЕЖИМЫ ПЕРЕХВАТА
----------------
- Системный прокси (по умолчанию): без прав администратора, заворачивает
  трафик приложений, которые уважают системные настройки прокси.
- TUN (галочка «Режим TUN»): перехватывает ВЕСЬ трафик системы. Требует
  подтверждения UAC (права администратора нужны для сетевого адаптера).

МАРШРУТИЗАЦИЯ
-------------
Вкладка «Маршрутизация» — упорядоченный список правил (домен/IP/порт/процесс
-> прокси/напрямую/блок), выигрывает первое совпавшее; что не подошло ни под
одно — уходит по правилу «остальной трафик». Правки применяются к работающему
ядру сразу, без потери соединения.

- Наборы правил: готовые (РФ напрямую, блок рекламы), удалённые по URL и
  текстовые списки доменов (.lst) — такой список приложение скачивает и
  конвертирует само.
- Группы нод: свои selector/urltest, чтобы разные правила уходили через разные
  ноды («торренты -> нода NL, остальное -> авто»).
- «Проверка домена» показывает, куда уйдёт домен, ещё до подключения.
- «Резать TLS-приветствие» у правил «Напрямую» — фрагментация приветствия,
  чтобы имя сайта попало на границу двух пакетов и простой DPI его не собрал.
  Добавляет к каждому соединению около 80 мс.

Поверх правил есть три режима — «Правила», «Глобально» (всё через прокси),
«Напрямую» (всё мимо). Переключаются мгновенно, без перезапуска ядра.

ТРАФИК И ЖУРНАЛ
---------------
Вкладка «Трафик» — что прямо сейчас идёт через ядро, каким маршрутом и по
какому правилу; оттуда же можно оборвать соединение или завести правило по
хосту/IP/процессу. Вкладка «Журнал» — лог ядра с фильтром по уровню и
подстроке; там же настраивается, что именно ядро пишет в лог.

ФАЙЛЫ
-----
- MitM.exe             — приложение.
- assets\              — ядра, wintun.dll, базы гео/rule-set.
- data\                — создаётся при первом запуске: профили, настройки,
                         правила, config.json, кэш и журнал ядра (box.log).

ДВА ЯДРА (в assets\)
--------------------
- sing-box.exe        — официальное стабильное ядро (по умолчанию).
- sing-box-xhttp.exe  — форк sing-box-lx с поддержкой транспорта XHTTP
                        (для нод type=xhttp; официальное ядро их не умеет).

Чтобы включить XHTTP: «Настройки» -> «Ядро» -> «Выбрать ядро...» -> выбери
sing-box-xhttp.exe из папки assets. Версия сменится на вариант -lx, появится
значок «своё». Кнопка «Сбросить» вернёт официальное ядро. Выбор запоминается и
переносится вместе с папкой (портативно, с любой буквы диска).

ЛИЦЕНЗИИ
--------
Приложение использует ядро sing-box (github.com/SagerNet/sing-box),
распространяемое под лицензией GPLv3, а также базы geoip/geosite.
Форк с XHTTP: github.com/Leadaxe/sing-box-lx (тоже GPLv3).
Ядро подключается как отдельный процесс. Исходники ядра: см. ссылки выше.
Флаги стран — набор circle-flags (MIT), шрифт Inter (SIL OFL 1.1).

Если антивирус ругается на sing-box.exe/wintun.dll — это ложное срабатывание,
типичное для VPN/прокси-инструментов; добавь папку в исключения.
